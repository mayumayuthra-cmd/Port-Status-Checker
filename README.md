# Port Status Checker

## Description
A Python project that checks whether a specific TCP port on a given host is open or closed.

## Features
- Accepts hostname or IP address.
- Accepts port number as input.
- Checks port connectivity.
- Displays port status.

## Technologies Used
- Python
- Socket Module

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
py port_status_checker.py
```

4. Enter the hostname and port number.
5. View the port status.
